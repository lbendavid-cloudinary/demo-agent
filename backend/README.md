# CopilotKit Runtime (TypeScript)

## Setup

```bash
pnpm install
```

## Environment

Set environment variables (for example in your shell):

```
export PORT=8001
export CORS_ORIGIN=http://localhost:5173
export STRANDS_AGENT_URL=http://localhost:8000/
```

## Development

```bash
pnpm dev
```

The runtime will be available at `http://localhost:8001/api/copilotkit`.
