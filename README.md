## Preperations

1. Install https://ollama.com/
2. Run it and install gpt-oss:20b 

## Running the agent

1. `uv sync`
2. `uv run python -u main.py`


## Running the backend (copilotkit runtime)

1. `cd backend`
2. `pnpm install`
3. `pnpm run dev`

## Running the UI

1. `cd frontend`
2. `pnpm install`
3. `pnpm run dev`
